# Woods Run Digest

Static public site for **Woods Run Digest**, the daily forestry and forest-products intelligence brief from The Forest Business School.

Public domain: `https://woodsrun.forestenterprise.org`

## Site structure

- `/` — latest edition / homepage
- `/archive/` — daily edition archive
- `/research/` — longer research pieces
- `/assets/` — shared site assets

The site is intentionally lightweight: plain HTML and CSS so that daily editions can be generated and published without a build step.
